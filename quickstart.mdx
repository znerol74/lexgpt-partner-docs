---
title: "Quickstart"
description: "In zwei Requests vom Thema zum verlinkten Rechtstipp — plus Feedback."
---

<Steps>
  <Step title="Anwalts-Token bereithalten">
    Der Tipp-Flow läuft pro Anwalt: du brauchst das **finditoo-WP-JWT** des
    eingeloggten Anwalts als Bearer-Token (ein reiner Service-Key wird bei
    `/rechtstipps` mit `403` abgewiesen). Details unter
    [Authentifizierung](/authentication).
  </Step>
  <Step title="Rechtstipp erstellen">
    Minimal genügt `topic` + `land`. `filters` weglassen → der Land-Default greift.
    Der Tipp wird gespeichert; die Response enthält eine **`id`**.

    ```bash
    curl -X POST https://dashboard.lex-gpt.ai/api/rechtstipps \
      -H "Authorization: Bearer $ANWALT_WP_JWT" \
      -H "Content-Type: application/json" \
      -d '{
        "topic": "Kündigungsfristen im Mietrecht",
        "kind": "rechtstipp",
        "land": "AT",
        "as_of": "2026-07-23"
      }'
    ```

    Neben der `id` enthält die Antwort den Artikel als `markdown` (mit
    `[§ …]`-Markern), `markdown_clean` (ohne Marker) und — für fertige Links —
    `markdown_linked` (Paragraphen bereits als `[Label](URL)`; siehe
    [Paragraphen verlinken](/guides/citations-links)). Die Generierung dauert
    ~1 Minute.
  </Step>
  <Step title="Feedback zurückgeben">
    Schick die **`id`** aus Schritt 2 als `target_id` — mehr braucht es nicht.
    Das Admin-Board zeigt dann automatisch Thema (Input) und Original-Text
    (Output) des Tipps. `session_id` ist optional (defaultet auf `target_id`);
    mit WP-JWT kommt die Anwalts-Identität automatisch.

    ```bash
    curl -X POST https://dashboard.lex-gpt.ai/api/feedback \
      -H "Authorization: Bearer $ANWALT_WP_JWT" \
      -H "Content-Type: application/json" \
      -d '{
        "content_type": "rechtstipp",
        "target_id": "3f1c2b4a-5d6e-7089-a1b2-c3d4e5f60718",
        "feedback": "green"
      }'
    ```

    Die Response enthält `stored: true`, wenn gespeichert wurde.
  </Step>
</Steps>

<Note>
  Verfügbare Länder: **AT** und **CH** — für die Schweiz einfach `land: "CH"`
  senden (Kantons-Scope optional via `filters.swissCantons`, siehe
  [Optionen](/guides/options)). `land: "DE"` liefert `400` (Roadmap).
</Note>
