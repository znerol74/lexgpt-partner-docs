Die LexGPT Partner API bietet zwei Kern-Funktionen für deine Integration:

<CardGroup cols={2}>
  <Card title="Rechtstipp erstellen" icon="file-pen" href="/guides/rechtstipps">
    Thema rein, recherchierter SEO-Artikel mit verlinkten Paragraphen raus —
    gespeichert, mit `id` fürs Feedback.
  </Card>
  <Card title="Feedback" icon="thumbs-up" href="/guides/feedback">
    Rückmeldung zu generierten Rechtstipps (und weiteren Inhalten).
  </Card>
</CardGroup>

## Basis-URL

```
https://dashboard.lex-gpt.ai/api
```

## Fläche

| Endpunkt | Zweck |
| --- | --- |
| `POST /rechtstipps` | Rechtstipp/Blog erstellen (gespeichert, liefert `id`) |
| `GET /rechtstipps` · `GET`/`PATCH`/`DELETE /rechtstipps/{id}` | Verlauf, laden, bearbeiten, löschen |
| `GET /rechtstipp/options` | Verfügbare Auswahlen pro Land |
| `POST /feedback` | Feedback abgeben (`target_id` = Tipp-`id`) |

<Note>
  Dies ist die öffentliche Partner-Fläche. Interne Endpunkte (Recherche-Chat,
  Admin) sind nicht Teil des Vertrags und können sich ohne Ankündigung ändern.
</Note>

<Info>
  Verfügbare Länder: **AT** und **CH** (`land: "CH"` inkl. Kantons-Filter).
  `DE` ist auf der Roadmap und liefert bis dahin `400`.
</Info>
