Im generierten Artikel stehen Quellen-Marker wie `[§ 1295 ABGB]` als **Text** im
`markdown`-Feld — sie sind noch **keine** Links. Die passenden URLs stecken pro
Quelle in `sources[].html_url`. Die API löst diese Zuordnung serverseitig auf, du
musst sie **nicht** selbst nachbauen.

<Note>
  Die **Erstellen-Response** von [`POST /rechtstipps`](/guides/rechtstipps)
  liefert alle drei Varianten. `markdown_tokenized` + `citations` werden
  **gespeichert** und kommen auch bei `GET`/`PATCH` zurück (nach einer
  Bearbeitung neu aufgelöst); nur die fertig verlinkten Felder
  (`markdown_linked`/`html_linked`) gibt es ausschließlich beim Erstellen — mit
  dem Snippet unten baust du sie jederzeit aus Tokens + Map nach.
</Note>

## Der einfache Weg: `markdown_linked`

Enthält die Paragraphen bereits als Markdown-Links `[§ 1295 ABGB](https://…)`.
Nimm einfach dieses Feld statt `markdown` — fertig.

<Warning>
  Die Quellen-Verlinkung löst aktuell **AT**-Quellen auf (RIS/EUR-Lex). Bei
  **CH**-Artikeln bleiben die Marker derzeit überwiegend unverlinkt
  (`matched: false`) — `markdown_linked` entspricht dann dem Text ohne Links;
  für die Veröffentlichung nimm `markdown_clean` bzw. `html`. Fedlex-Links für
  CH sind in Arbeit.
</Warning>

<Info>
  Brauchst du eigene Chips oder ein eigenes Quellen-Panel, nutze stattdessen
  `markdown_tokenized` + `citations` (granulare Kontrolle, siehe unten).
</Info>

## Granular: aus `markdown_tokenized` + `citations`

`markdown_tokenized` ist der Artikel, in dem jeder Marker durch `{{CITATION_n}}`
ersetzt ist. `citations[n]` beschreibt die Auflösung:

```json
{
  "index": 0,
  "marker": "§ 1295 ABGB",
  "label": "§ 1295 ABGB",
  "matched": true,
  "source_index": 3,
  "url": "https://www.ris.bka.gv.at/…"
}
```

Ersetze jedes Token durch `[label](url)` (bei Treffer) bzw. `[marker]` (ohne):

```js
function linkify(tokenized, citations) {
  return tokenized.replace(/\{\{CITATION_(\d+)\}\}/g, (_, i) => {
    const c = citations[Number(i)];
    if (!c) return "";
    return c.matched && c.url ? `[${c.label}](${c.url})` : `[${c.label}]`;
  });
}
```

<Note>
  Nicht jeder Marker findet eine Quelle (`matched: false`) — z. B. Mehrfach-§§
  wie `§§ 30, 31 IO`. Diese bleiben in `markdown_linked` bewusst unverlinkter
  Text, damit nie ein falscher Link entsteht. Die Citation trägt dann aber ein
  `parts`-Array mit jedem Teil einzeln aufgelöst (`§ 30 IO`, `§ 31 IO` — je mit
  `matched`/`url`), falls du Mehrfachzitate selbst granular verlinken willst.
</Note>

## Sauberer Veröffentlichungstext

Willst du den Text **ohne** Marker und **ohne** Links (z. B. als Kopiervorlage),
nimm `markdown_clean` bzw. `html`.
