---
title: "Verfügbare Optionen"
description: "Default-Filter und gültige Auswahlwerte pro Land abfragen."
---

<Info>
  Für die meisten Integrationen genügt der Default-Pfad (nur `topic` + `land`
  senden, `filters` weglassen). Den Options-Endpunkt brauchst du nur, wenn der
  Anwalt die Auswahl granular steuern soll.
</Info>

`GET /rechtstipp/options?country=AT` liefert pro Land **beides**: den
Default-Filter-Block **und** die gültigen Auswahlwerte je Feld. Damit kannst du
einen Selektor bauen, ohne Werte hart zu kodieren.

```bash
curl https://app.lex-gpt.ai/api/rechtstipp/options?country=AT \
  -H "Authorization: Bearer $LEXGPT_TOKEN"
```

## Antwort (Form)

```json
{
  "country": "AT",
  "default": {
    "geographic": ["bundesrecht"],
    "legislation": true,
    "judikatur": true,
    "courts": [],
    "germanCourts": [],
    "swissCantons": [],
    "eurlex": true,
    "documentTypes": []
  },
  "options": {
    "geographic": [
      { "value": "bundesrecht", "label": "Bundesrecht" },
      { "value": "wien", "label": "Wien" },
      { "value": "niederoesterreich", "label": "Niederösterreich" }
    ],
    "courts": [
      { "value": "Justiz", "label": "Ordentliche Gerichte (inkl. OGH)" },
      { "value": "Vfgh", "label": "Verfassungsgerichtshof (VfGH)" },
      { "value": "Vwgh", "label": "Verwaltungsgerichtshof (VwGH)" }
    ],
    "documentTypes": [],
    "flags": [
      { "value": "legislation", "label": "Gesetze/Legislation" },
      { "value": "judikatur", "label": "Judikatur/Entscheidungen" },
      { "value": "eurlex", "label": "EU-Recht (EUR-Lex)" }
    ]
  }
}
```

<Note>
  Die `geographic`-Werte sind die ASCII-Slugs, die das Retrieval direkt
  akzeptiert (`niederoesterreich`, `kaernten` …) — übernimm sie 1:1 in
  `filters.geographic`. Anfangs ist nur `country=AT` befüllt; `DE`/`CH` liefern
  `400`, solange die Länder nicht freigeschaltet sind.
</Note>
