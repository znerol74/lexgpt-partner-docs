`POST /feedback` speichert eine Rückmeldung. Für Rechtstipps genügt die **`id`**
aus der [Erstellen-Response](/guides/rechtstipps) als `target_id` — du musst vom
Tipp **nichts** mitsenden. Das Admin-Board verknüpft über die `id` und zeigt
Thema (LLM-Input) und Original-Text (LLM-Output) des Tipps.

## Minimaler Payload (Rechtstipp)

```bash
curl -X POST https://dashboard.lex-gpt.ai/api/feedback \
  -H "Authorization: Bearer $ANWALT_WP_JWT" \
  -H "Content-Type: application/json" \
  -d '{
    "content_type": "rechtstipp",
    "target_id": "3f1c2b4a-5d6e-7089-a1b2-c3d4e5f60718",
    "feedback": "green",
    "comment": "Sehr brauchbar"
  }'
```

## Felder

| Feld | Pflicht | Beschreibung |
| --- | --- | --- |
| `feedback` | ✓ | Wert (siehe unten). |
| `target_id` | ✓ (Rechtstipp) | Die **`id`** aus der Erstellen-Response → verknüpft das Feedback mit dem Tipp. |
| `content_type` | – | `rechtstipp` (bzw. `blog`) setzen; Default `ask`. |
| `session_id` | – | Gruppierungs-ID; fehlt sie, defaultet der Server auf `target_id`. |
| `comment` | – | Freitext. |
| `target_title` | – | Nur Fallback-Anzeige, falls kein `target_id`-Join greift. |
| `user_name`, `user_email` | – | Nur ohne WP-JWT nötig (siehe Identität). |

## Werte

Kanonisch ist die Ampel:

- `green` — gut
- `yellow` — teils
- `red` — schlecht

Für Daumen-UIs werden `positive` → `green` und `negative` → `red` gemappt. Sende
also einen der fünf Werte.

## Identität des Anwalts

<CardGroup cols={2}>
  <Card title="Mit WP-JWT (empfohlen)" icon="user-check">
    Reiche das finditoo-Token des Anwalts als Bearer durch — `user_name`/
    `user_email` werden **automatisch aus dem Token** aufgelöst. Nichts weiter nötig.
  </Card>
  <Card title="Mit Service-Key" icon="key">
    Kein Anwalts-Kontext im Token → gib `user_name` und `user_email` im Body an,
    sonst fehlt die „welcher Anwalt"-Info.
  </Card>
</CardGroup>

## Response

```json
{ "stored": true }
```

<Note>
  Kein stiller Verlust mehr: lässt sich das Feedback keiner Identität zuordnen,
  kommt `{ "stored": false, "reason": "…" }` zurück statt einer leeren 200.
</Note>
